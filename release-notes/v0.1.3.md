## New
- **Zoom and Google Meet:** add a video call when creating an event. Google Meet on Google calendars, Zoom on any calendar once you connect Zoom in Settings › Accounts.
- **Settings in pages,** with a search box to find any setting.
- **Updates finish by themselves:** a "Restart to update" button appears when a new version is ready, and Coo updates quietly while it sits in the menu bar.
- **New mail banners** now show while you're using Coo too. Prefer just the sound? Settings › Notifications › Show.
- **New events** show where they'll land on the calendar while you fill in the details.

## Fixed
- Single messages no longer look like a conversation, and the newest message in a thread opens automatically.
- The update window shows these notes instead of a web page.
- Sharing sign-ins with AI agents works without Keychain prompts (from 0.1.2).
