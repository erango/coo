## Improved
- In dark mode, notices like "Archived … Undo" are now light, so they stand out from the panes the way they already did in light mode.
- The sidebar's folder and calendar lists use Coo's thin scrollbar, without a solid track, when macOS is set to always show scroll bars.
- In Settings, Hebrew account names line up on the left with the rest.

## Fixed
- After the screen woke up, a Hebrew message could show the first letter of each line twice. Coo now redraws messages when its window comes back.
