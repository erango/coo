## New
- **Formatting in the composer:** a toolbar for text size, bold, italic, underline, strikethrough, text color, highlight, lists, indent, alignment, quotes, links, code and clearing formatting, with the usual shortcuts (⌘B, ⌘I, ⌘U, ⌘K, ⇧⌘7 / ⇧⌘8, ⌘] / ⌘[ and more; see Settings › Keyboard shortcuts).
- **Lists as you type:** start a line with "1. ", "- " or "* " to begin a list. Press Enter on an empty item to end it, or Backspace to undo the list.
- **Emoji:** :) :D ;) <3 and friends turn into emoji as you type (Backspace brings the text back), and a new emoji button opens a searchable picker.
- **Code:** wrap text in `backticks` for inline code, or start a line with ``` for a code block.
- **Spam:** mark messages as spam or not spam from the toolbar, the right-click menu, the Message menu or with "!". Microsoft accounts can also report phishing. AI agents can do this too.
- **Check for Updates** now shows what's happening: checking, up to date, downloading, ready to restart, or what went wrong.

## Fixed
- In an inline reply, recipients no longer cover Cc and the other buttons when the window is narrow or the text size is larger.
- Formatting buttons are sharper on non-Retina displays.
