## New
- **Select several messages:** ⌘-click to pick messages one by one, ⇧-click for a range. Archive, delete, move, flag or mark them read all at once, with one Undo.
- **Verified senders:** a green check next to the sender's name when the mail provably came from the domain shown.
- **Signatures page:** one default signature for every address, and a short list to give any address its own signature or none.
- **Copy a subject** with the button that appears when you hover over it, or select it with the mouse.
- **After archive or delete:** choose whether the next message opens or the message just closes (Settings › General).
- **Dock badge:** turn off the unread count on the app icon (Settings › Notifications).

## Fixed
- Outlook messages read on another device no longer turn into "(unknown)" rows at the bottom of the list.
- Switching mailboxes closes the message that was open in the previous one.
- Keyboard shortcuts in Settings are grouped by task and easier to scan.
- Long addresses in the sender card stay on one line.
- Toggles show the pointer cursor, the list's hover color no longer covers the scrollbar, and the "Coo is still running" note fits its text.
